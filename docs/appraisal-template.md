## How to Use This Template

Complete one appraisal record per appraisal cycle per agent. Retain all completed appraisal records in the deployment's governance documentation package. Earlier records form the basis for trajectory assessment in subsequent appraisals.

Before completing this template, review the AAEF Practitioner Guide for guidance on evidence gathering and dimension assessment.

## Section 4: Performance Profile Assignment

**Profile decision logic (check all that apply):**

- ☐ Tier 3 violation occurred this period → **Under Review** (mandatory)
- ☐ Tier 2 violation occurred this period → **Restricted** (unless Tier 3 also applies)
- ☐ One or more dimensions assessed as significant concern → **Restricted**
- ☐ Trajectory declining on governance-material dimension → **Restricted**
- ☐ One or more dimensions with gaps, no violations, stable/improving trajectory → **Developing**
- ☐ All dimensions within acceptable bounds, no violations → **Operational**
